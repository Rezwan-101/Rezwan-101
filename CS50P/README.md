
# CS50P – Introduction to Programming with Python

## 📌 Project Overview

This repository contains my solutions and practice exercises from **CS50's Introduction to Programming with Python (CS50P)** by Harvard University.

Throughout this course, I explored fundamental and intermediate Python programming concepts by solving problem sets and implementing practical programming exercises.

The main goal of this repository is to document my Python learning journey, strengthen my problem-solving skills, and build a solid foundation for further studies in software development and AI/ML engineering.

## 🧠 Topics Covered

- Functions and Variables
- Conditionals
- Loops
- Exceptions
- Libraries
- Unit Tests
- File I/O
- Regular Expressions
- Object-Oriented Programming

## 🎯 Learning Outcomes

By completing these exercises, I aim to develop the following skills:

1. **Python Fundamentals:** Understand variables, data types, functions, and basic syntax.
2. **Problem Solving:** Break down programming problems and implement logical solutions.
3. **Control Flow:** Apply conditions, loops, and exception handling.
4. **Data Handling:** Work with files, strings, lists, and dictionaries.
5. **Code Organization:** Use functions, modules, and libraries effectively.
6. **Testing:** Write unit tests and debug Python programs.
7. **OOP:** Understand classes, objects, methods, and object-oriented programming principles.
8. **Regular Expressions:** Use regex for pattern matching and text processing.
